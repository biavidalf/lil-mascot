# Lil Mascot

Um companheiro de desktop para escolher um próximo passo e começar uma sessão curta de foco.

## Baixar

Instale a [versão mais recente](https://github.com/biavidalf/lil-mascot/releases/latest) no **Windows 64 bits**. Na página da versão, escolha o arquivo que termina em `Setup.exe`. O aplicativo instalado verifica novas versões e oferece a atualização sem exigir outro link de download.

Leia o [guia de primeiros passos](GUIA-PRIMEIROS-PASSOS.md) para conhecer os recursos e enviar feedback.

Os dados da jornada ficam no computador da pessoa que usa o app. O instalador ainda não tem assinatura digital; confirme que o download veio deste repositório antes de decidir continuar caso o Windows mostre um aviso.

Este repositório distribui instaladores e documentação. O desenvolvimento do aplicativo acontece em um repositório privado.
